# Сервис поиска благотворительных мероприятий

Консольное приложение для поиска благотворительных мероприятий и регистрации
пользователей на них. Проект продолжает исходный сценарий ПР1: сохраняет
проверку возраста и поиск по направлению, а также добавляет работу с
коллекциями, JSON-файлами и регистрациями.

## Сущности

- мероприятие — название, направление, город, дата, возрастное ограничение и вместимость;
- организация — название и контактные данные благотворительного фонда;
- пользователь — имя, возраст и e-mail;
- регистрация — связь пользователя с мероприятием, дата и статус.

## Возможности

- просмотр всех мероприятий с организацией и количеством свободных мест;
- поиск по названию, описанию, направлению и городу;
- сортировка по дате, названию или городу;
- проверка минимального возраста и доступности мест;
- создание и отмена регистрации;
- просмотр собственных регистраций;
- сводная статистика по мероприятиям и регистрациям;
- обработка ошибок пользовательского ввода и повреждённых JSON-файлов.

## Структура проекта

```text
main.py                  консольное меню и сценарии пользователя
events.py                поиск, сортировка и добавление мероприятий
organizations.py         поиск организаций
users.py                 создание и поиск пользователей
registrations.py         доступность, создание и отмена регистраций
storage.py               чтение и запись JSON через with open(...)
reports.py               статистика
utils.py                 проверка возраста и безопасный ввод
data/*.json              постоянные данные приложения
tests/                   автоматизированные тесты pytest
```

## Формат хранения

Данные хранятся в файлах `data/events.json`, `data/organizations.json`,
`data/users.json` и `data/registrations.json`. Каждый файл содержит список
JSON-объектов. Связи задаются идентификаторами: `organization_id`, `user_id`
и `event_id`. Отмененная регистрация не удаляется, а получает статус
`"Отменена"`.

## Запуск

```bash
python main.py
```

Для установки инструментов разработки и запуска проверок:

```bash
pip install -r requirements.txt
pytest
flake8 .
```

На этапе ПР2 классы и объекты предметной области не используются: данные
представлены списками словарей, а поведение разделено между функциями и
модулями. Объектная модель может быть добавлена на следующем этапе.
