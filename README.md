# Сервис поиска благотворительных мероприятий

## Назначение
Программа помогает пользователю находить благотворительные мероприятия по интересующему направлению.

## Целевая аудитория
Люди, которые хотят участвовать в благотворительных и волонтерских мероприятиях.

## Предметная область
Благотворительные мероприятия и волонтерская деятельность.

## Основные сущности
- пользователь;
- благотворительное мероприятие;
- направление помощи.

## Основные функции
- поиск мероприятий по направлению;
- просмотр информации о мероприятии;
- проверка подходящего возраста для участия.

## План развития
На следующих этапах планируется:
- добавить больше мероприятий;
- добавить поиск по городу;
- разработать веб-приложение на Django;
- подключить базу данных;
